# Fortnite YouTube Thumbnail Portfolio

Creative and interactive portfolio combining a custom-built website with a collection of original Fortnite YouTube thumbnails.

## Project Overview
This project showcases both:
- A responsive, interactive portfolio website built with HTML, CSS, and vanilla JavaScript.
- A curated selection of custom-designed Fortnite YouTube thumbnails created to maximize CTR.

The website features a dynamic before/after comparison system to highlight the transformation from raw renders to final thumbnails, along with animated preview thumbnails and a full portfolio gallery.

## Features
- Before / After thumbnail comparison
- Interactive portfolio grid 3x3
- Dark, minimalist visual style
- Responsive layout

## Tech Stack
- HTML5
- CSS3 (animations and transitions)
- Vanilla JavaScript
